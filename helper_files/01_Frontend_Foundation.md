# AI Resume Analyzer - Frontend Master Prompt (Antigravity)

## IMPORTANT INSTRUCTIONS

Read the entire prompt before generating code.

This repository contains **ONLY the frontend** of an AI Resume Analyzer
& Recruitment platform.

### Strict Rules

-   Build ONLY frontend code.
-   Do NOT generate backend (Node.js, Express, Python, Java, etc.).
-   Do NOT generate APIs.
-   Do NOT generate database schemas.
-   Do NOT generate authentication services.
-   Do NOT generate AI models or ATS algorithms.
-   Do NOT generate mock candidates, jobs, resumes or analytics unless
    explicitly requested.
-   Do NOT modify project architecture unless necessary.
-   Use React + Vite.
-   Use Tailwind CSS.
-   Use Framer Motion only for meaningful micro-interactions.
-   Prefer reusable components over duplicated code.

## Design Philosophy

Create a premium SaaS application inspired by: - Linear - Notion -
Vercel - GitHub - Stripe Dashboard

The interface should feel minimal, elegant, fast and highly
professional.

## Layout

Use a permanent desktop sidebar with: - Dashboard - Resume - ATS - JD
Match - AI Interview - Applications - Resources - Profile - Settings

Top navbar: - Search - Notifications - Theme toggle - User profile

## Theme

-   Neutral background
-   Primary blue accent
-   Rounded cards (16px)
-   Soft shadows
-   Consistent spacing (8px grid)
-   Responsive desktop-first
